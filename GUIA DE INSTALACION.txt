GUÍA DE INSTALACIÓN Y PRUEBAS

CREAR BASE DE DATOS:
1. mysql -u root -p
2. node scripts/setup-db.js
3. node scripts/seed.js

INICIAR SERVIDOR:
npm install
npm start
-> http://localhost:3000

PRUEBA 1 - REGISTRO Y LOGIN:
- Abrir /registro
- Nombre: Prueba User | Correo: prueba@test.com | Clave: test123
- Login con esos datos
-> Redirige a /catalogo

PRUEBA 2 - SOLICITAR PRÉSTAMO:
- En catálogo, click en "Solicitar préstamo" (ej. Don Quijote)
-> Mensaje: " Solicitud enviada. Código: ABC123"
- Ir a "Mis préstamos" -> Estado: pendiente

PRUEBA 3 - APROBAR (ADMIN):
- Login: admin@biblioteca.com / admin123
- Panel Admin -> Préstamos
- Click "Aprobar"
-> Estado: prestado | Stock libro: 2 → 1 | Fecha límite: +14 días

PRUEBA 4 - DEVOLUCIÓN (ADMIN):
- En préstamos, click "Devolver"
-> Estado: devuelto | Stock: 1 → 2

PRUEBA 5 - VALIDACIÓN DUPLICADOS:
- Login usuario normal (juan@example.com / juan123)
- Solicitar mismo libro dos veces
-> Mensaje: "Ya tienes un préstamo activo"
